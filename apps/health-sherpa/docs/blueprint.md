# Health Sherpa: original feature list

## Core features

- Document upload: drag and drop for health documents (PDF, images).
- Document analysis: parse with a Gemini model, de-identify, extract insights that help answer questions.
- Confidence display: colour rating (green 90 and up, yellow 70 to 89, orange 50 to 69, red under 50) with clickable citations.
- Chat: conversational guidance based on the parsed documents.
- Session summary export: downloadable summary with key insights, questions for the provider, de-identified information. Planned as PDF; built as JSON.
- Provider mode: toggle to view summaries formatted for clinical decision support.
- De-identified history modal: optional report of which PHI identifiers were anonymized.

## Style

- Primary: sky blue (#7DD3FC). Calm, clear.
- Background: light desaturated blue (#F0F9FF).
- Accent: soft teal (#99F6E4) for key actions and insights.
- Clean sans-serif type.
- Minimal icons for document types and actions.
- Chat and document insights stay easy to reach.
